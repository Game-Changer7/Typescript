## 🧠 TypeScript Function Styles Cheat Sheet

| 🧩 Style                         | 📝 Syntax                                                                                                                                     | 🔧 Description                | ✅ Best For                 | ⚠️ Notes                          |
|----------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------|-----------------------------|-----------------------------------|
| 🟦 **Named Function Declaration** | `function greet(name: string): string { return "Hello " + name; }`                                                                           | Classic style with name       | Reusability, Hoisting       | Hoisted to top of scope          |
| 🟨 **Anonymous Function Expression** | `const greet = function(name: string): string { return "Hello " + name; };`                                                                 | Assigned to a variable        | Closures, Callbacks         | Not hoisted                      |
| 🟩 **Arrow Function (Lambda)**    | `const greet = (name: string): string => "Hello " + name;`                                                                                   | Short, concise syntax         | React props, Array methods  | `this` is lexically scoped       |
| 🟧 **Function Constructor**       | `const greet = new Function("name", "return 'Hello ' + name;");`                                                                             | Dynamic function creation     | Eval-like use               | Not type-safe; rarely used       |
| 🟪 **Method in Object**          | `const obj = { greet(name: string): string { return "Hello " + name; } };`                                                                   | Function as object method     | OOP patterns                | `this` refers to the object      |
| 🟥 **Class Method**              | `class Greeter { greet(name: string): string { return "Hi " + name; } }`                                                                     | OOP, reusable method          | Services, Models            | Use with `new` keyword           |
| 🟫 **Arrow in Object Property**  | `const obj = { greet: (name: string): string => "Hey " + name };`                                                                            | Inline concise method         | Callbacks                   | No own `this`                    |
| 🔷 **Optional Parameter**        | `function greet(name?: string): string { return "Hi " + (name || "Guest"); }`                                                                | Optional args                 | User defaults               | Must handle `undefined`          |
| 🔸 **Default Parameter**         | `function greet(name: string = "Guest") { return "Hi " + name; }`                                                                            | Default fallback              | Cleaner optional values     | Must be at end                   |
| 🔹 **REST Parameters**           | `function sum(...nums: number[]): number { return nums.reduce((a, b) => a + b); }`                                                            | Multiple args                 | Variadic args               | Always returns an array          |
| ⚫ **Function Overloading**       | `function add(a: number, b: number): number; function add(a: string, b: string): string; function add(a: any, b: any) { return a + b; }`     | Different signatures           | Versatile APIs             | Only last has implementation     |
| 🟤 **Generic Function**          | `function identity<T>(arg: T): T { return arg; }`                                                                                             | Reusable, type-safe           | Libraries, utils            | Can constrain with `<T extends>` |
